## Modelagem inicial da base bruta

Foi criada uma modelagem visual inicial para representar as tabelas originais da base Olist e seus relacionamentos principais. 

Objetivo:
Facilitar o entendimento da estrutura dos dados antes da definição do modelo analítico no PostgreSQL.

Observação:
Essa modelagem representa a base bruta e poderá ser refinada posteriormente conforme a seleção das tabelas e campos mais relevantes para a análise.
